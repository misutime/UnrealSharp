# 问题记录目录

本目录存放**逐个问题的完整记录**：前因后果、原因与机制、解决方案与实施计划、证据索引。
目标是**可追溯**：任何人在任何时候都能从"症状 / 日志"追到"根因、修复、验证、残余风险"。

## 目录与命名约定

```
docs/问题/
  目录说明.md                     ← 本文件（约定 + 索引）
  日期-简短中文名/                 ← 一个问题一个目录，日期取"首次确诊/修复"日（如 2026-09-22）
    问题说明.md                   ← 该问题的首页：症状、状态、文件清单、时间线、证据索引
    原因与机制.md                 ← 前因后果：执行模型背景 + 根因 + 精确调用链 + 影响面 + 上游追溯
    解决方案.md                   ← 解决方案 / 实施计划：复核意见、交付物、验证、风险、待决定项
    （必要时再加）证据/、复现/、补丁/
```

**每个问题目录必须包含三件套**：① 前因后果（`原因与机制.md`）；② 解决方案（`解决方案.md`）；③ 首页索引与证据（`问题说明.md`）。
**跨问题复用的内容不进问题目录**：编码规范放 `docs/` 根目录，机制与工具通识放 `docs/插件使用笔记.md`。
